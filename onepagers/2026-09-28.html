Fully Byzantine-Resilient Multi-Agent Reinforcement Learning

skim

Haejoon Lee, Dimitra Panagou

Agents learning together by actor-critic reinforcement learning can cross-check each message against two-hop copies, so that compromised communication links no longer pull the learned parameters away from what they would have been without an attack.

Problem
Earlier Byzantine-resilient actor-critic methods only guarantee that parameters end up near the attack-free solution, so an adversary on the network permanently costs some performance. Nobody had shown convergence to exactly the attack-free limit points in a fully decentralized setting.
Method
Each agent receives the same neighbor information over several two-hop paths and uses that redundancy to spot and throw out tampered messages, then runs ordinary consensus-based actor-critic updates on what is left. The proof assumes linear function approximation for both the value function and the team reward, and it assumes the attacks are edge attacks, meaning the agents themselves are honest and only the messages are corrupted. They define a new graph redundancy condition, give a way to build networks that meet it, and show the condition can be checked in polynomial time.
Results
The main result is a proof that parameters converge almost surely to the attack-free limit points over time-varying graphs. The only experiments are cooperative multi-robot formation control tasks, and the abstract gives no numbers, no baselines and no team sizes.
Caveat
The exact-recovery guarantee depends on two strong restrictions. Adversaries may only corrupt links, not act as malicious agents, and value and reward functions must be linear. On top of that, the redundancy condition probably needs dense networks with many two-hop paths, which a sparse and fast-changing set of vehicles talking over wireless links is unlikely to provide. The formation control demo gives no evidence of how the method handles packet loss, delay, or agents that do not take part.

Why it mattersThis is peripheral to your work. It concerns learning shared parameters under adversarial messages, not negotiating maneuvers or exchanging trajectories. The one idea you could borrow is checking a message against redundant two-hop relays, which could apply to verifying relayed intentions in a maneuver coordination protocol. But their threat model is tampering, not the loss and delay you study.
